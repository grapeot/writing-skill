# Twitter 导流文案写作工作流（twitter_post_writing）

## 元数据

- **类型**：Workflow（external writing 的渠道子工作流）
- **适用场景**：从一篇已通过双重 gate 的文章生成 Twitter 导流文案（Typefully long post，中文）。发布动作本身（创建 draft、schedule）归发布层 skill，不在本文件内。
- **上游**：`workflow_external_writing.md`（文章层工作流与 gate 哲学）。
- **创建**：2026-08-21；2026-08-22 改版为"结构复用"路线（v2，见陷阱表最后两行：另起结构的两次实测失败）。
- **执行者**：调用方 agent 编排；生成走 `agy --print`（Antigravity CLI，独立上下文），机械检查走 lint CLI 与确定性命令。

## 0. 核心原则：复用文章结构，只治文风

文章写作时，结构是投入最重的部分（writing_brief 的 H2 规划按读者理解顺序设计过）。文案的职责是**按文章的章节顺序顺叙压缩**，不另起结构、不重新发明 hook。历史上 20 条文案的 AI 味出在文风层（模板句式、格言堆砌、祈使收尾、事实漂移），不在结构层——结构跟着文章走，文风用 prompt 约束 + 机械 gate 治理。

反模板问题的解法也随之改变：文案结构继承文章结构的多样性，不靠轮换表。多篇文章本身结构雷同导致文案雷同时，才做例外处理（如从文章第 2 节的事实起笔）。

## 1. 工作流总览

```
文章 MD ──→ 单次 AGY 生成（读文章全文，按章节顺序压缩成 ~400 字推文，文风约束内置）
        └─→ Gate A（机械：lint 适用子集 + tweet 特有检查，必须清零）
        └─→ Gate B（事实保真：数字/量词/限定词逐项对照文章）
             └─→ tweet_final.md（交付给发布流程）
```

生成调用不看不看旧文案（防锚定）。之前的两阶段隔离（初稿→独立重写）在 v2 中取消：它的目的是阻断"金句最大化抽取"，但实测隔离后的重写反而丢结构；改为单次生成直接携带结构与文风约束，靠 gate 兜底。

## 2. 生成 prompt 核心（单次，可直接使用）

独立 `agy --print` 调用（`gemini-3.7-flash-high`，`--print-timeout 10m`，scratch 目录内执行，prompt 用绝对路径）：

> 读下面这篇文章，写一条 Twitter 导流长推文。
> 1. **心态：转述，不是摘要**。想象给同事转述一篇刚读完的分析：挑着讲、关键处放慢、用自己的口语连接（"从数据上看""说白了""这就导致"）。摘要心态会让每句话高效推进，读起来赶；转述心态有快有慢。
> 2. **结构**：按文章的章节顺序顺叙，每节 1-2 句。文章开头用什么事实入场，推文就用什么入场；对照、转折、判断落在文章所在位置。中心判断（thesis）用陈述式写清楚，不许弱化或删除。
> 3. **认识运动的节奏（关键）**：假设与裁决分成自然段，各自呼吸。假设段带不确定的缓冲词（"一开始直觉觉得大概是……"），裁决句慢下来（"从数据上看，这种解释不成立"）。**禁止"起初容易以为X，查完发现Y"式连动压缩句**——两个动作挤一句就是赶路。新闻/分析类文风不用第一人称，但无主语句不等于压缩句。
> 4. **细节出场带功能**：选具体细节的标准是读者能立刻感知它证明什么。讲了细节讲不出 so what（如"每打一杯 shot 泵机启动一次"而不说明它是消费即工业计量、游客站在生产线最前端），就换细节或补一句功能。
> 5. **文风**：亲切自然的分析同行口吻。允许轻微口语连接词，句子长短错落——慢段（展开讲透一个点）和快段（一句带过）交替，不是每段满效率。亲切感来自节奏和具体细节，不来自人称、俚语、感叹和比喻装饰。
> 6. **禁用**：唯一/恰恰/绝不/才是真正的/根本；"不是A而是B"；"看似/表面是A，其实/真正是B"反转；排比与对仗；祈使句收尾；"一句话带走"式总结；"当……"前置从句；"很+形容词"评价标签；破折号；揭秘腔（"原来学术界把这种叫作X"，术语平实当名字用）。装饰性金句一律不要；文章原文最凝练的判断可保留原文式表达，全篇至多一处。
> 7. **长度与负荷**：380-480 字。数字只留承重的，口径、量词、限定词原样；禁止自行计算倍数或比率；禁止把单案例推成普遍规律。
> 8. 末行放本文 URL（发布层提供），正文提外部对象只写名字，禁止任何裸域名 token。全篇不得出现"我"作为叙述主语。
> 文章全文：<文章内容>

## 3. Gate A：机械检查（必须全部清零）

```bash
python -m writing_skill.external_prose_lint_cli tweet_final.md --json
```

适用映射（`h2_count`、`embedded_links`、`title_book_marks` 对推文无意义，忽略）：

| 规则 | 判定 |
|---|---|
| `em_dash` / `eval_label` / `polarity` / `meta_preamble` / `not_x_but_y` / `when_clause` / `banned_word` / `bracket_gloss` | HARD，必须为 0 |
| `quotes` / `bei_passive` / `single_sentence_paragraph` | REVIEW，逐条给保留理由（连续单句段 ≥4 要合并） |
| `bare_url` | 特殊：全篇恰好 1 个且在最后一行，必须是本文的 tracked 分发 URL（自有站点域名 + UTM，域名由发布层 overlay 提供） |

tweet 特有补充检查：

```bash
grep -c '^#' tweet_final.md          # 必须为 0（无标题）
grep -cE 'https?://' tweet_final.md  # 必须为 1
grep -cE '[a-zA-Z0-9.-]+\.(com|net|org|ai|dev|io)' tweet_final.md  # URL 行以外的裸域名必须为 0
grep -c 我 tweet_final.md            # 必须 0（或仅直接引语内，逐个说明）
sed '$d' tweet_final.md | grep -oE '[0-9][0-9.,]*%?' | wc -l       # 数字 token ≤6（软预算，超 1 个须在 notes 说明取舍）
```

调用方 agent 只允许机械级修正（破折号换冒号、删多余引号），修完重跑；需要语义改动就带着具体问题重跑生成，不许自己凭语感改稿。

## 4. Gate B：事实保真（对照文章）

1. **数字与量词机械核对**：提取文案全部数字、百分比、倍数、量词，逐个在文章全文中检索。文案出现文章没有的数字（含自行计算的倍数/比率）、量词口径改变（人次→场次）→ 阻断重跑。
2. **限定词核对**：文案每个强断言回到文章对应段落，检查限定词是否丢失、单案例是否被推成普遍规律。漂移 → 阻断。
3. **结构核对**：文案的入场事实、对照位置、判断位置与文章章节顺序一致；thesis 在场且为陈述式。缺失或错位 → 打回。

Gate B 必须逐项贴出对照结果，禁止自述"核对过了"。

## 5. 验收标准

一个没参与生成的 agent 只看产物应能判定：

1. Gate A 全部清零，lint stdout 与补充检查输出已落盘；
2. Gate B 对照表已落盘，零漂移；结构与 thesis 核对通过；
3. 文章的中心判断在场（陈述式）；除它之外无装饰性金句；无排比对仗收尾；
4. 结构与文章章节顺序一致（notes 里给出逐节对应）；
5. 末行唯一 tracked 分发 URL，slug 正确；
6. 380-480 字，无 Markdown 标题；
7. 无第一人称叙述主语（`grep -c 我` = 0，引语除外）。

自然语言"检查过了没问题"而无命令输出 → 定义为 gate 失败。

## 6. 已知陷阱（均实际发生过）

| 陷阱 | 表现 | 应对 |
|---|---|---|
| 金句最大化抽取 | 文案专挑文章最对称、最绝对的句子，删证据留判词 | 文风禁用清单 + 装饰性金句 ≤0（thesis 除外） |
| 压缩制造数字漂移 | "16 倍""人次→场次""年年上涨" | Gate B 数字逐个回文章检索，倍数必须原文已有 |
| 文章本身无认识运动 | 生成硬找心路历程会幻觉 | 顺叙压缩天然不需要；按文章实际有的东西写 |
| 亲切被做成装饰 | 堆俚语、感叹、比喻、套近乎 | 亲切操作化为"无主语发现叙述 + 轻口语连接词 + 句子呼吸" |
| 亲切被误操作为第一人称 | "有对话感"变成"我起初/我以为" | prompt 明令禁止"我"作叙述主语；gate 有 grep |
| 降负荷做成信息扫地出门 | 一条线执行把承重证据删光，文案空泛 | 预算只限数字 token，不限承重事实 |
| 另起结构：事件线替代分析线（uipath v2 实测） | "压缩"被执行成新闻帖（发布→功能→机制→观望），thesis 和承重对照被砍，文章最值钱的判断丢失 | v2 改为结构复用：按文章章节顺叙，thesis 陈述式在场，承重对照不砍 |
| 另起结构：抽取式重写丢结构（uipath v3 实测） | 隔离重写虽保 thesis 但重排叙事（微软开场），用户判定不如照文章顺序的旧版结构 | 同上；旧版文案的结构优势来自文章本身，复用它 |
| 节奏急（实测，用户反馈） | 无主语认识运动被写成连动压缩句（"起初容易以为X，查完发现Y"），假设与裁决挤一句快进，读感赶；细节出场不带功能（气动泵 shot 讲不出 so what）；盲评模型按红线打分判不出此病，人类体感才暴露 | 假设段与裁决段分开、各带缓冲词；禁连动压缩句；细节带功能句出场；生成心态从"摘要"改为"转述" |
| agy 并行会话串线 | 同时跑多个 `agy --print` 时串到无关会话，读错 prompt、写错文件 | 同 scratch 目录串行执行；绝对路径；产出先验证非空对题 |

## 7. 输出规格

`tweet_final.md`：首行即对外正文，末行 URL，无内部标注。同目录保留生成 prompt、lint/核对 stdout，供审计与失败重跑。
